📖 Câu 1: So sánh StyleSheet.create() và Inline Style

StyleSheet.create() tối ưu hóa bằng cách gửi Style ID (số nguyên) qua JavaScript Bridge thay vì toàn bộ object trong mỗi lần render, đồng thời kiểm tra lỗi chính tả lúc khởi chạy.

📖 Câu 2: Flexbox trong React Native vs CSS Web

Hướng trục chính mặc định là flexDirection: 'column', không có đơn vị px/rem/em, display chỉ hỗ trợ 'flex' hoặc 'none', tính toán bởi Yoga Engine C++.

📖 Câu 3: Các thuộc tính căn chỉnh chính

justifyContent (trục chính), alignItems (trục phụ), alignSelf (ghi đè cá nhân), flexWrap: 'wrap' và gap.

📖 Câu 4: Kỹ thuật Responsive UI

Sử dụng useWindowDimensions() kết hợp breakpoint 640px để chuyển đổi linh hoạt giữa 1 cột dọc (Mobile) và 2 cột song song (Tablet/PC).

📖 Câu 5: Box Model trong React Native

Mặc định là border-box và hoàn toàn KHÔNG xảy ra hiện tượng Margin Collapsing (chập lề) như trên CSS Web.
